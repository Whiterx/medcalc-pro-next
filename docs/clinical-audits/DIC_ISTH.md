# ISTH overt DIC score — технический и источниковый аудит

**Инструмент:** ISTH overt DIC score, классическая версия 2001 и дополнительное обновление ISTH SSC 2025.  
**Популяция:** взрослые пациенты с основным заболеванием, известным как ассоциированное с ДВС; оценка overt (явного) ДВС.  
**Статус:** В РАБОТЕ  
**Первоисточник классической версии:** Taylor FB Jr et al. Thromb Haemost. 2001;86(5):1327–1330. PMID 11816725.  
**Обновление:** Iba T et al. J Thromb Haemost. 2025;23(7):2356–2362. DOI 10.1016/j.jtha.2025.03.038.  
**Российские КР:** «Сепсис (у взрослых)», 2024, ID 898_1; «Внематочная беременность», 2024, приложение Г2.

## 1. Основное условие применения

ISTH overt DIC score применяют только при наличии основного заболевания, ассоциированного с ДВС. Сумма ниже 5 не исключает раннюю фазу или disease-specific коагулопатию. Score не является самостоятельным диагнозом и не определяет лечение.

## 2. Классическая версия ISTH 2001

| Показатель | Баллы |
|---|---:|
| Тромбоциты >100×10⁹/л | 0 |
| 50–100×10⁹/л | 1 |
| <50×10⁹/л | 2 |
| D-димер/ФДП: повышения нет | 0 |
| Умеренное повышение | 2 |
| Значительное повышение | 3 |
| Удлинение ПВ <3 с | 0 |
| 3–6 с | 1 |
| >6 с | 2 |
| Фибриноген >1 г/л | 0 |
| <1 г/л | 1 |

Сумма ≥5 совместима с overt ДВС; <5 — критерии overt ДВС не достигнуты, но ранний/неявный ДВС не исключён. При overt score ≥5 повторяют оценку ежедневно; при <5 и сохраняющемся подозрении — через 1–2 дня или раньше при ухудшении.

## 3. Обновление ISTH SSC 2025

| Показатель | Баллы |
|---|---:|
| Тромбоциты <50×10⁹/л | 2 |
| 50–<100×10⁹/л | 1 |
| ≥100×10⁹/л | 0 |
| D-димер ≤3×ВГН | 0 |
| >3×ВГН | 2 |
| >7×ВГН | 3 |
| Удлинение ПВ <3 с | 0 |
| ≥3 и <6 с | 1 |
| ≥6 с | 2 |
| Фибриноген <1 г/л | 1 |

Порог overt ДВС — сумма ≥5. Кратность D-димера определяется относительно ВГН именно используемого лабораторного метода; FEU и DDU нельзя смешивать без корректного пересчёта.

Публикация 2025 года — коммуникация ISTH SSC с предложением обновлённого определения и критериев. Она не заменяет disease-specific алгоритмы ранней коагулопатии и пока не отражена в указанных российских КР 2024.

## 4. Российские клинические рекомендации

- КР РФ «Сепсис (у взрослых)» 2024, ID 898_1: рекомендуют стандартизированные лабораторные исследования для диагностики ДВС (тромбоциты, фибриноген, ПВ/МНО, АЧТВ, D-димер и др.), но не устанавливают универсальную замену disease-specific критериям.
- КР РФ «Внематочная беременность» 2024, приложение Г2: приводят классическую шкалу ISTH 2001 для диагностики явного ДВС с кровотечением.
- Поэтому классическая ISTH 2001 установлена версией по умолчанию; обновление ISTH SSC 2025 доступно как дополнительная международная версия, а не как новая российская схема.

## 5. Проверка реализации и ограничения

- Проверены пороги тромбоцитов, ПВ, фибриногена и D-димера для обеих версий.
- Порог overt DIC ≥5.
- Обязательны основное заболевание и подтверждение, что лабораторные показатели относятся к одному клиническому периоду.
- Удалены произвольные верхние пределы для тромбоцитов, удлинения ПВ, фибриногена и кратности D-димера: исходные критерии не задают таких максимумов. Остаются проверки конечного неотрицательного числа.
- Классическая версия использует качественную оценку D-димера/ФДП по локальным лабораторным референсам; обновление 2025 — кратность ВГН.
- Не использовать для самостоятельного назначения трансфузий, антикоагулянтов или иной терапии. Учитывать основное заболевание, фенотип кровотечения/тромбоза и динамику.
