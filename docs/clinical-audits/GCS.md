# Glasgow Coma Scale (GCS) — технический и источниковый аудит

**Инструмент:** Glasgow Coma Scale, взрослая шестибалльная двигательная версия  
**Популяция:** взрослые и дети старше 5 лет без педиатрической модификации; для младших детей требуется возрастная модификация.  
**Статус:** ПРОВЕРЕН — технический и источниковый аудит завершён; клиническая валидация врачами запланирована после релиза  
**Первоисточник:** Teasdale G, Jennett B. Assessment of coma and impaired consciousness. A practical scale. Lancet. 1974;2:81–84.  
**Расширенная двигательная шкала:** Teasdale G, Jennett B. Assessment and prognosis of coma after head injury. Acta Neurochir Suppl (Wien). 1976;34:45–55.  
**Актуальная стандартизация:** Glasgow Coma Scale official structured approach and GCS Assessment Aid.

## 1. Компоненты и баллы

| Компонент | Баллы | Современное описание |
|---|---:|---|
| Открывание глаз (E) | 4 | Спонтанно |
|  | 3 | На звук |
|  | 2 | На давление |
|  | 1 | Отсутствует |
| Речевая реакция (V) | 5 | Ориентирован |
|  | 4 | Спутанная речь |
|  | 3 | Отдельные слова (Words) |
|  | 2 | Звуки (Sounds) |
|  | 1 | Отсутствует |
| Двигательная реакция (M) | 6 | Выполняет команды |
|  | 5 | Локализует давление |
|  | 4 | Нормальное сгибание |
|  | 3 | Патологическое сгибание |
|  | 2 | Разгибание |
|  | 1 | Отсутствует |

Общий балл — сумма E+V+M, диапазон 3–15, только если все три компонента можно оценить. Компоненты всегда фиксируются отдельно вместе с суммой.

## 2. Терминологическое расхождение

Актуальная структурированная методика разработчиков GCS использует упрощённые формулировки V3 «Words» и V2 «Sounds», а для шестибалльной двигательной шкалы — M4 «Normal flexion» и M3 «Abnormal flexion». Это отражает обновление терминов и расширенную двигательную шкалу, принятую после исходной публикации 1974 года.

КР Минздрава РФ «Очаговая травма головного мозга» 2022 (ID 732_1, взрослая популяция; плановый пересмотр не позднее 2024) в приложении Г1 сохраняют более ранние русскоязычные формулировки: V3 «словесная окрошка», V2 «нечленораздельные звуки», M4 «отдёргивание конечности». КР остаётся важным источником клинического контекста ЧМТ, но срок планового пересмотра прошёл. Для терминологии универсального калькулятора используется актуальная структурированная методика разработчиков; числовые значения компонентов остаются теми же. Категории тяжести нарушения сознания из КР по ЧМТ не добавляются в универсальный GCS-калькулятор.

## 3. Непроверяемые компоненты (NT)

- Если компонент нельзя надёжно оценить из-за интубации/трахеостомии, седации, паралича, языкового барьера, нарушения слуха/речи, афазии, травмы глаз/лица или повреждения спинного мозга, он обозначается NT.
- NT не заменяется 1 или 0.
- При любом NT общий балл не рассчитывается и не сообщается; доступные компоненты E/V/M продолжают документироваться и использоваться для динамического наблюдения.
- При интубации обычно NT относится к речевому компоненту, если речь действительно не может быть оценена; E и M по-прежнему оцениваются отдельно.

## 4. Структурированная оценка

Официальный GCS Assessment Aid предлагает последовательность: проверить факторы, мешающие оценке; наблюдать реакцию; при необходимости использовать стандартизированную звуковую и физическую стимуляцию; оценить наилучший ответ. Необходимо применять наименьший стимул, достаточный для получения реакции, и учитывать локальные противопоказания к стимуляции.

## 5. Педиатрическая применимость

Официальная методика допускает стандартную шкалу без модификации у детей старше 5 лет. У детей младше 5 лет и младенцев необходима педиатрическая модификация; текущий калькулятор её не реализует.

## 6. Программная реализация и тесты

Проверяются:
- диапазоны E 1–4, V 1–5, M 1–6;
- сумма 3–15 и корректная запись E/V/M;
- NT в каждом компоненте и отсутствие общей суммы при любом NT;
- запрет пустых, нечисловых и выходящих за диапазоны значений;
- соответствие описаний V3, V2 и M4 актуальной терминологии;
- отсутствие предзаполненных значений и очистка результата при изменении/сбросе.

## 7. Ограничения

- GCS описывает уровень сознания/реактивности; не является самостоятельным диагнозом или полноценной неврологической оценкой.
- Общая сумма не заменяет фиксацию компонентов и клинического контекста.
- Седация, паралич, интубация, нарушения коммуникации и сопутствующие повреждения могут делать отдельные компоненты NT.
- Педиатрическая модификация не реализована.
- КР РФ 732_1 датированы 2022 годом и имели срок пересмотра не позднее 2024; актуальность следует перепроверять при клиническом применении.
