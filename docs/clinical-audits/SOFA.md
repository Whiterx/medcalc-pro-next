# Клинический аудит: SOFA-1

Дата начала: 27.11.2026  
Статус: **В РАБОТЕ**  
Приоритет: высокий  
Инструмент: оригинальная SOFA (не SOFA-2), взрослые пациенты.

## 1. Источники и иерархия

1. Российские клинические рекомендации Минздрава России «Сепсис (у взрослых)», ID 898_1, 2024, приложение Г.1: https://cr.minzdrav.gov.ru/preview-cr/898_1. Текст приложения и таблицы: https://disuria.ru/_ld/16/1641_kr24A40A41MZ.pdf.
2. Оригинальная публикация: Vincent JL, Moreno R, Takala J, et al. The SOFA (Sepsis-related Organ Failure Assessment) score to describe organ dysfunction/failure. Intensive Care Med. 1996;22:707–710. DOI: 10.1007/BF01709751. https://www.esicm.org/wp-content/uploads/2018/03/esicmworking5-2.pdf.
3. Sepsis-3: https://jamanetwork.com/journals/jama/fullarticle/2492881 — для контекста ΔSOFA и определения сепсиса.
4. SOFA-2 (2025): отдельная версия шкалы, не подменяет оригинальную SOFA в этом калькуляторе: https://jamanetwork.com/journals/jama/fullarticle/2840822.

Российские КР применяются для соответствующего взрослого септического контекста. Оригинальная методика используется для уточнения характеристик шкалы там, где КР не задают однозначный ответ. SOFA-1 и SOFA-2 не смешивать.

## 2. Популяция и назначение

- Взрослые.
- Шесть систем органов: дыхательная, коагуляционная, печёночная, сердечно-сосудистая, центральная нервная система, почки.
- Каждая система: 0–4 балла; сумма 0–24.
- Оригинальная SOFA предназначена для последовательного описания органной дисфункции, а не как самостоятельный прогнозный индекс или диагностический тест.
- В оригинальной методике используются наихудшие значения каждого параметра за сутки; они не обязаны быть получены в один момент времени. Оценка повторяется ежедневно.
- ΔSOFA ≥2 при подозреваемой инфекции используется в Sepsis-3 как операциональный критерий органной дисфункции; это не самостоятельный диагноз сепсиса.

### Дыхательная система
PaO₂/FiO₂: <400 — 1; <300 — 2; <200 с респираторной поддержкой — 3; <100 с поддержкой — 4. Текущая функция реализует эти вложенные пороги. Граница 400/300/200/100 должна оставаться строго проверенной.

### Коагуляция
Тромбоциты: <150 — 1; <100 — 2; <50 — 3; <20 — 4. Границы 150/100/50/20 тестируются.

### Печень
Билирубин: 20–32 — 1; 33–101 — 2; 102–204 — 3; >204 мкмоль/л — 4. Границы тестируются. Вход в UI — целое значение мкмоль/л.

### Сердечно-сосудистая система
MAP <70 — 1; добутамин любой дозы — 2; дофамин и адренергические препараты по соответствующим диапазонам. В оригинальной публикации введение препаратов должно продолжаться не менее 1 часа.

**Найденное и исправленное расхождение:** до изменения код относил дофамин ровно 5 мкг/кг/мин к 2 баллам. Российские КР ID 898_1 указывают <5 для 2 баллов и 5–15 для 3 баллов. Функция исправлена: <5 → 2; 5–15 → 3; >15 → 4.

Для эпинефрина/норэпинефрина российские КР задают <0,1 для 3 и >0,1 для 4, не описывая точное 0,1. Оригинальная публикация Vincent et al. задаёт ≤0,1 для 3; это правило использовано для заполнения граничного пробела, без введения нового режима.

**Исправление интерфейса:** добавлено обязательное пустое по умолчанию подтверждение, что выбранные препараты вводились не менее 1 часа. Без подтверждения расчёт не выполняется.

### Центральная нервная система
GCS 13–14 — 1; 10–12 — 2; 6–9 — 3; <6 — 4. При NT общий балл не рассчитывается; NT не подменяется нулём. Сохранить предупреждение о влиянии седации, интубации и других факторов.

### Почки
Креатинин: 110–170 — 1; 171–299 — 2; 300–440 — 3; >440 — 4 мкмоль/л. Диурез <500 мл/сут — 3; <200 мл/сут — 4. Если доступны оба показателя, берётся более высокий балл. Важно сохранять 24-часовой период для диуреза.

## 4. Версия и ограничения

- Это оригинальная SOFA-1, а не SOFA-2.
- Не использовать для детей.
- Нужны худшие значения каждого компонента за сутки; калькулятор не собирает временной ряд и не выбирает автоматически худшее значение.
- Калькулятор не устанавливает диагноз сепсиса, не назначает лечение и не заменяет клиническую оценку.
- Исходный SOFA не следует автоматически считать равным 0 при известной предшествующей органной дисфункции.
- NT по GCS блокирует итоговую сумму, чтобы не приравнивать отсутствующую оценку к норме.
