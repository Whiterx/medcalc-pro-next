# Клинический и технический аудит: SOFA-2

Дата начала: 27.11.2026  
Статус: **В РАБОТЕ**

Популяция: взрослые пациенты ОРИТ.

Российские КР, которые бы переопределяли именно SOFA-2, в рамках текущей проверки не выявлены. Приоритет — точное следование опубликованной методике SOFA-2; SOFA-1 и SOFA-2 не смешивать.

## 2. Популяция и ограничения

- Шесть систем: головной мозг, дыхательная, сердечно-сосудистая, печень, почки, гемостаз.
- Каждая 0–4; сумма 0–24.
- Разработка и валидация проведены на взрослых пациентах ОРИТ; экстраполяция на детей и пациентов вне ОРИТ требует отдельного подтверждения.
- Шкала описывает органную дисфункцию; не является самостоятельным диагнозом и не заменяет клиническую оценку.
- Данные для последовательной оценки должны относиться к согласованному временному окну; нельзя смешивать несопоставимые периоды.

## 3. Опубликованные пороги

### Головной мозг
GCS 15 — 0; 13–14 — 1; 9–12 — 2; 6–8 — 3; 3–5 — 4. При невозможности полной GCS применяется лучшая двигательная реакция по таблице методики. Потребность в лекарственной терапии делирия даёт не менее 1 балла. При седации используется последняя GCS до седации; если она неизвестна, правило методики требует особой обработки, а не произвольного клинического предположения.

### Дыхательная система
PaO₂/FiO₂: >300 — 0; ≤300 — 1; ≤225 — 2; ≤150 с advanced ventilatory support — 3; ≤75 с advanced ventilatory support или ECMO — 4. SpO₂/FiO₂ — альтернативный показатель только при отсутствии PaO₂ и SpO₂ <98%, с отдельными порогами, которые должны быть подтверждены по полной таблице и сноскам оригинала. Без advanced support обычно применяется ограничение оценки; исключения связаны с недоступностью поддержки или ceiling of treatment.

### Сердечно-сосудистая система
MAP ≥70 без вазопрессоров/инотропов — 0; MAP <70 без них — 1. Сумма норэпинефрина и эпинефрина ≤0,2 мкг/кг/мин либо любой дозы другого вазопрессора/инотропа — 2. Сумма >0,2–≤0,4 — 3; низкая сумма ≤0,2 вместе с другим вазопрессором/инотропом — 3. Сумма >0,4 или средняя сумма >0,2–≤0,4 вместе с другим препаратом либо механическая поддержка — 4. Вазоактивные препараты учитываются при введении ≥1 часа.

### Печень
Общий билирубин ≤20,6 мкмоль/л — 0; ≤51,3 — 1; ≤102,6 — 2; ≤205 — 3; >205 — 4.

### Почки
Креатинин ≤110 мкмоль/л — 0; ≤170 — 1; ≤300 — 2; >300 — 3. Дополнительные критерии: диурез <0,5 мл/кг/ч за 6–12 ч — 1; <0,5 за ≥12 ч — 2; <0,3 за ≥24 ч или анурия 0 мл ≥12 ч — 3. Получение RRT или выполнение критериев для RRT (включая хроническое применение) — 4.

### Гемостаз
Тромбоциты >150 ×10⁹/л — 0; ≤150 — 1; ≤100 — 2; ≤80 — 3; ≤50 — 4.

## 4. Предварительный аудит реализации

Файлы:
- `src/calculators/emergency/sofa2.ts`

- `src/calculators/emergency/sofa2.test.ts`

Обнаруженные и исправляемые риски:
1. Расчётное ядро трактовало отсутствие и креатинина, и диуреза как 0 баллов; теперь это должно быть `null` и блокировать общий балл.
2. При отсутствии вазоактивной поддержки отсутствие MAP не должно превращаться в 1 балл; при поддержке MAP не обязателен. Расчётное ядро должно различать эти ситуации.
3. Изменение доз норэпинефрина/эпинефрина после подтверждения ≥1 часа должно сбрасывать подтверждение.
4. Измеряемые значения могут иметь десятичную часть; нельзя требовать целочисленности без основания в первоисточнике.
5. Проверить все точные границы, сочетания препаратов, длительность, ECMO, респираторную поддержку, моторную шкалу, RRT и неполные данные.

Статус остаётся «В РАБОТЕ» до завершения сверки всех сносок оригинальной публикации, тестов, UI-валидации и CI. Экспертная клиническая валидация врачами планируется после релиза и не должна блокировать текущий технический аудит.

## 5. Источниковые ограничения

SOFA-2 опубликована как отдельная обновлённая шкала; нельзя подменять её порогами SOFA-1. Не следует представлять результат как диагноз или как индивидуальный прогноз летальности. В статье валидация ориентирована на ICU mortality; это ограничение должно быть отражено в интерпретации.


## 6. Дополнительные правила первоисточника, выявленные при чтении сносок

Полная таблица и сноски JAMA/методологического протокола уточняют следующие правила, отсутствовавшие в исходном UI:
- Если дофамин используется как единственный вазопрессор: ≤20 мкг/кг/мин — 2 балла; >20–≤40 — 3; >40 — 4.
- Если вазоактивные препараты недоступны или исключены из-за ceiling of treatment, MAP оценивается отдельными порогами: ≥70 — 0; 60–69 — 1; 50–59 — 2; 40–49 — 3; <40 — 4.
- Норэпинефрин должен вводиться в расчёт как основание; дозу соли нельзя напрямую подставлять без пересчёта по конкретной лекарственной форме.
- Вазоактивный препарат учитывается при непрерывной внутривенной инфузии не менее 1 часа.
- ECMO по дыхательной недостаточности даёт 4 балла дыхательной системе. ECMO по сердечно-сосудистым показаниям (включая VA-ECMO) автоматически даёт 4 балла и дыхательной, и сердечно-сосудистой системам.
- При отсутствии advanced respiratory support максимальная дыхательная оценка 2 балла, кроме недоступности поддержки или ceiling of treatment.
- Для SpO₂/FiO₂: ≤300 — 1; ≤250 — 2; ≤200 + поддержка — 3; ≤120 + поддержка или ECMO — 4; SpO₂ должна быть <98%, PaO₂/FiO₂ недоступно.

В код добавлены отдельные поля дофамина, доступности вазоактивной терапии и VA-ECMO; уточнены пороги MAP, логика обоих органных компонентов при VA-ECMO, обязательное подтверждение непрерывной инфузии ≥1 часа и пересчёт дозы норэпинефрина на основание. Добавлены граничные тесты.
