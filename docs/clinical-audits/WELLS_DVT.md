# Wells score for deep vein thrombosis — технический и источниковый аудит

**Инструмент:** двухуровневая шкала Wells для ТГВ нижней конечности.  
**Популяция:** взрослые пациенты с клиническим подозрением на ТГВ нижней конечности.  
**Статус:** ПРОВЕРЕН — технический и источниковый аудит завершён; клиническая валидация врачами запланирована после релиза  
**Российские КР:** «Тромбоз глубоких вен конечностей», 2025, ID 960; раздел 2.2.1, приложение Г1.  
**Первоисточник:** Wells PS et al. Evaluation of D-dimer in the diagnosis of suspected deep-vein thrombosis. N Engl J Med. 2003;349:1227–1235.

## 1. Критерии и баллы

| Критерий | Баллы |
|---|---:|
| Активное онкологическое заболевание | +1 |
| Паралич/парез или недавняя иммобилизация нижней конечности гипсовой повязкой | +1 |
| Постельный режим ≥3 дней или большая операция в последние 12 недель под общей/регионарной анестезией | +1 |
| Локальная болезненность по ходу глубокой венозной системы | +1 |
| Отёк всей ноги | +1 |
| Разница окружности голеней ≥3 см (10 см ниже бугристости большеберцовой кости) | +1 |
| Ямочный отёк, ограниченный симптомной ногой | +1 |
| Коллатеральные поверхностные вены (не варикозные) | +1 |
| Ранее документированный ТГВ | +1 |
| Альтернативный диагноз как минимум столь же вероятен | −2 |

Диапазон от −2 до 9 баллов. Все десять критериев должны быть оценены; отрицательное значение каждого бинарного признака может быть принято только после фактической клинической оценки.

## 2. Интерпретация по КР РФ 2025

- ≥2 баллов — ТГВ вероятен.
- ≤1 балла — ТГВ маловероятен.

КР РФ 2025 рекомендуют Wells для оценки вероятности ТГВ у взрослых. Шкала не подтверждает и не исключает диагноз самостоятельно.

## 3. Диагностический контекст

- При низкой клинической вероятности КР РФ 2025 позволяют рассмотреть D-димер как альтернативу УЗ-исследованию для исключения ТГВ.
- При высокой клинической вероятности и/или повышенном D-димере, если первичное УЗИ отрицательно, рекомендуется повторное дуплексное или триплексное сканирование через 7 дней.
- Дальнейший выбор исследования определяется клинической картиной, доступностью и действующим диагностическим алгоритмом; калькулятор не назначает лечение.

## 4. Ограничения популяции

- Взрослые пациенты с подозрением на ТГВ нижней конечности.
- Не использовать для бессимптомного скрининга, тромбоза вен верхней конечности, детей, беременности или диагностики рецидива ТГВ без отдельного алгоритма.
- Балл не является основанием для назначения или отмены антикоагулянта.

## 5. Безопасность интерфейса и проверка реализации

Обнаружено, что прежняя реализация позволяла рассчитать 0 баллов при всех чекбоксах по умолчанию снятыми без явного подтверждения, что врач действительно оценил каждый критерий. Это создавало риск трактовать неполный ввод как отсутствие всех признаков.

Исправление: добавлено отдельное обязательное подтверждение, что все десять критериев оценены и неотмеченные признаки действительно отсутствуют. Подтверждение не добавляет баллы и не является одиннадцатым критерием. Без подтверждения расчёт блокируется.

Проверяются:
- сумма −2…9;
- каждый из девяти положительных критериев +1;
- альтернативный диагноз −2;
- порог 1/2 балла;
- все десять критериев и обязательное подтверждение;
- измерение окружности голени на 10 см ниже бугристости большеберцовой кости;
- отсутствие предзаполненных значений и очистка при сбросе.
